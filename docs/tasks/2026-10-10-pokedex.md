# Task: Pokédex of caught Pokémon

**Assigned to:** agy  **Lead / reviewer:** claude  **Second review:** codex (read-only)

## Goal
Every Pokémon you name correctly is "caught" and saved in the browser. A "Pokédex 23/151" button in the score bar
opens a grid of all 151: caught ones show their official art, name and type badges; the rest show only their number.
"Back" returns to the quiz exactly where you left it.

## Files you may touch (nothing else)
- `src/pokedex.ts`, `src/pokedex.test.ts` (new)
- `src/main.ts`, `src/main.test.ts`
- `src/style.css`

## Runtime boundary
Browser only. Caught ids live in `localStorage` key `pokequest.pokedex` as a JSON array of numbers, e.g. `[1,25,150]`.
Names, art and types come from the existing `api.getPokemon(id)` (it caches). Tests never touch the network: use the
fake api and fake storage like the existing tests. No new dependencies. Build every Pokédex element with
`createElement` / `textContent`: never `innerHTML` with API data.

## API (write exactly these)
```ts
// src/pokedex.ts
export const POKEDEX_KEY = 'pokequest.pokedex';
export const DEX_SIZE = 151;
export function loadCaught(storage?: Storage): number[];                 // sorted, unique, integers 1..151 only
export function addCaught(caught: number[], id: number): number[];       // new sorted array, input not mutated
export function saveCaught(storage: Storage | undefined, caught: number[]): void;
```

## Look
Pokédex replaces the quiz inside the same card. Header: title "Pokédex", the count, and a "Back" button. Grid:
`repeat(auto-fill, minmax(72px, 1fr))`, small square cells; caught cells show the art (64px) with the name under it,
uncaught cells are dimmed with just the number. Type badges are small pills with a colour per type (Gen-1 types:
normal, fire, water, grass, electric, ice, fighting, poison, ground, flying, psychic, bug, rock, ghost, dragon; also
steel and fairy). The grid scrolls inside the card (max-height ~60vh). Works on a phone width.
